🧠 Tiny LLM Lab

A real (but very small) language model that runs entirely in your browser. It learns to predict the next letter — that's the same trick ChatGPT uses, just with ~4,000 numbers instead of hundreds of billions.

2 · Teach it

Give it some text to read. It plays "guess the next letter" thousands of times and tweaks its dials a little after every wrong guess.

Only letters a–z, spaces and full stops are kept. Try typing your own!

Too slow = takes forever. Too fast = it overshoots and gets confused. Try both!

3 · Talk to it

Type the start of a sentence. The brain only ever does one thing: say how likely each letter is to come next. Click a letter to add it!

Low creativity = always picks the favourite. High = takes more risks (and makes more typos).

4 · Rate its writing (feedback)

Training on text is like studying a textbook. This is like having a teacher: it writes something, you say 👍 or 👎, and it nudges its dials to write more (or less) like that. Chat assistants get polished this way — it's called learning from human feedback.

Things to try

  • Ask it to write before training. Then train 500 steps. Then 3,000. Watch gibberish turn into words.
  • Pick the Counting reading material and prompt three four . Does it know what comes next?
  • Pick Random robot. The score can't get near 0 — why? (Because the text itself is random; nobody can guess it!)
  • Type a word it has never seen into the prompt. What does it guess?
  • Put a super high learning speed on. What happens to the score line?
  • It can only see the last 16 letters. Write a long prompt — which letters does it ignore?
  • Make your own reading material with just a few sentences. It will memorise them!
  • Make samples and give 👎 to the typo ones, 👍 to the good ones. Does the next sample get better?
  • Train only ~150 steps (typos everywhere), then start the robot teacher. Watch “real words” climb with no new reading!
  • Let the robot run for a minute, then make a sample. Every word is real… but is it good writing? The brain found a trick: repeating one safe word ("is is is is"). The robot only checks spelling, so that's a perfect score! This is called reward hacking — a real problem for AI makers.
  • Turn the feedback strength up high on the robot. Too strong and it forgets how to write — the same as too-fast learning speed.
